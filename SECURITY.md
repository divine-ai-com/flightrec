# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `v0.1.x` | Yes |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/divine-ai-com/flightrec/security/advisories/new) on this repository. We will acknowledge receipt within 2 working days and provide a remediation timeline after triage.
