# Security Policy

## Supported Versions

Only the latest minor release of each module receives security fixes.

| Module | Supported |
| --- | --- |
| `github.com/divine-ai-com/flightrec` | `v0.2.x` |
| `github.com/divine-ai-com/flightrec/grpcflightrec` | `v0.2.x` |
| `github.com/divine-ai-com/flightrec/otelflightrec` | `v0.2.x` |
| `github.com/divine-ai-com/flightrec/notifier/redisnotifier` | `v0.3.x` once released |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/divine-ai-com/flightrec/security/advisories/new) on this repository. We will acknowledge receipt within 2 working days and provide a remediation timeline after triage.
